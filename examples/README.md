Kanonischer .atc-Programm-Korpus (einziger Stand; keine Duplikate):
`atc8300.atc`, `atcos_main.atc`, `event_bus.atc`, `kernel.atc`, `main.atc`,
`shivamon.atc`. Wird fuer Frontend-/Verifizierer-Konformanz des Rust-Kerns
(crates/atc-core) weiterverwendet.

Die Python-Referenz-Implementierung ist seit 2026-09-17 vollstaendig
dokumentiert unter `docs/reference/python/` und aus dem Repository entfernt
(Rust-only, siehe README "Architecture boundary").
